# Example games

Real games from new.playhanabi.com, used by the tests (`tests/helpers.py`), the design docs and the review
tool (`review/run.sh`).

| File | What it is |
|---|---|
| `export_78921.json` | `new.playhanabi.com/export/78921`, unchanged (2 players, 6 suits, ends in a strikeout; the game in screenshots 1–2) |
| `export_78822.json` | `new.playhanabi.com/export/78822`, unchanged (3 players, 6 suits; the game in screenshot 3) |
| `export_78922.json` | `new.playhanabi.com/export/78922`, unchanged (2 players, No Variant, default options): the test game captured live as table 43267 |
| `decision_78921_turn4.json` | The decision record for UI turn 4, embedded in `docs/representation.md` §8. Generated by `python3 -m hanabi_data decision examples/export_78921.json 4 --pretty` |
| `live_43267_player0_*.txt` | That game's `gameActionList` websocket messages as seat 0 (harikari.live) received them: after the deal, after turns 3 and 10 (own cards hidden), and after the end (unhidden). One message per file, verbatim. See `docs/representation.md` §3.4 |

## What they have been checked against

- **78921:** at turns 4 and 10, the score, clue count, strikes, deck count, pace, stacks, hand contents,
  slot positions and clue touches match screenshots 1 and 2.
- **78822:** at turn 6 the same fields, plus the discard pile, match screenshot 3.
- 78921 and 78822 also match hanab.live's own reducer at every position (`review/oracle`, run by
  `review/server/bundle.py`).
